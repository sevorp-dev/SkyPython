# Android wheels for SkyPython

Python packages with native code, built for SkyPython's CPython 3.14 on Android
(API level 24+). Generated by `.github/workflows/build-wheels.yml` on `main`;
this branch is replaced by a single new commit on every publish. Do not edit by hand.

- `index.json` — catalogue read by the app: for every project, one entry per ABI
  (`arm64-v8a`, `x86_64`, `armeabi-v7a`, `x86`) with the file name, version, SHA-256,
  size and `requires` (other projects of this index needed at runtime).
- `SHA256SUMS` — checksums of the wheel files.
- `*.whl` — the wheels, downloadable at
  `https://raw.githubusercontent.com/sevorp-dev/SkyPython/wheels/<file>`.

## Licenses

Each wheel carries the license texts of everything it contains in
`*.dist-info/licenses/` (or `*.dist-info/LICENSE*`).

### numpy

- **NumPy** — BSD-3-Clause, plus the permissively licensed components listed in its
  `LICENSE.txt` (https://github.com/numpy/numpy).
- **OpenBLAS** (64-bit numpy wheels, vendored as `numpy.libs/libopenblas-*.so`) —
  BSD-3-Clause (https://github.com/OpenMathLib/OpenBLAS), binary from Chaquopy's
  `chaquopy-openblas` (MIT packaging): `OpenBLAS-LICENSE.txt`.
- **LLVM libc++** (vendored as `numpy.libs/libc++_shared-*.so` on 64-bit, linked
  statically on 32-bit) — Apache-2.0 WITH LLVM-exception: `libc++-LICENSE.txt`.
